# 界面说明

## 面板布局

连接键盘后，驱动页右下角会出现 **Better ZetsuMeow Driver** 面板。面板渲染在
Shadow DOM 中，不受官方页面样式影响，也不会改动官方页面的布局。

- 标题栏：显示名称，右侧有展开 / 收起按钮。
- **主面板** 页签：连接状态、页面指纹、帧数、SDK 状态，以及备份 / 还原 / Wooting 导入操作。
- **设置** 页签：界面语言。
- 日志区：显示最近的操作进度、安全视图切换和警告。

![收起状态的面板：仅剩标题栏、状态点、运行徽标与 ＋ 按钮](/screenshots/panel-collapsed.png)

*面板收起后只保留标题栏，再点 ＋ 可重新展开。*

## 信息区

| 字段 | 含义 |
| --- | --- |
| **状态** | 脚本与设备连接的当前状态，见下表 |
| **指纹** | 官方驱动页面资源的 SHA-256 校验摘要，例如 `fw 1.1.1 · idx 1cd39f45 · hid … · scr …`；用于判断页面版本是否仍与脚本基线一致 |
| **帧数** | 观察到的帧计数，格式为 `总数 (hid 数 / serial 数)`。连接后操作键盘，计数应持续增长 |
| **SDK** | 内置 SDK 是否正常加载 |

![主面板页签：信息区四字段与一次备份后的操作日志](/screenshots/panel-main-info.png)

*已连接状态下的主面板：上方为信息区字段，下方日志区记录了一次完整备份的各步骤。*

指纹列的常见取值：

| 显示 | 含义 |
| --- | --- |
| `fw 1.1.1 · idx … · hid … · scr …` | 已读取到固件版本和页面资源哈希 |
| `not checked` | 尚未完成指纹检查；刷新页面后通常会重新检查 |
| `product mismatch` | 官方页面的产品表与脚本基线不一致 |
| `protocol mismatch` | 捕获到的回包无法按当前协议解析 |
| `unavailable` | 当前环境无法计算指纹（例如缺少 WebHID / Web Serial） |

## 连接状态

| 面板显示 | 含义 | 建议 |
| --- | --- | --- |
| **未连接（等待设备）** | 脚本已注入，官方页尚未连接键盘 | 在官方驱动页连接键盘 |
| **已连接** | 产品表、页面指纹和协议校验通过，可以正常读写 | 可以备份、还原、导入 |
| **通过 tap 代理连接** | 仍能观察页面连接，但页面资源哈希或固件不在已知基线内，脚本进入只读观察模式 | 先备份；写入不保证生效，建议更新脚本或等待适配 |
| **已禁用** | 当前环境不具备 WebHID / Web Serial，或产品表与协议不匹配 | 换用桌面版 Chrome / Edge；确认使用官方驱动页 |

状态旁的小圆点会随状态变色，并在有错误时显示为错误色。状态变化的原因会写入日志，
例如 `原因：…` 一行。

## 操作区

**主面板** 页签在发布版包含：

| 操作 | 说明 |
| --- | --- |
| **备份** | 读取当前配置，随后立即下载 `zmeow-config-<时间戳>.json` |
| **还原** | 打开“还原设备配置”对话框，选择备份文件并确认后写入设备 |
| **导入 Wooting 配置** | 输入分享码后点击 **导入**，转换并写入设备 |
| **设置** | 在 **设置** 页签切换简体中文 / English |

所有写操作都需要用户点击触发，浏览器据此授予设备或文件访问权限。

## 设置

设置页只有一个语言选项：

- 首次运行时按浏览器语言自动选择；检测到中文优先使用简体中文，否则使用 English。
- 手动切换后立即生效，并保存在驱动页的 `localStorage`（键名 `zmeow-tap.locale`）。
- 语言只影响脚本面板，不改变官方驱动页面的语言。

![设置页签：界面语言选项](/screenshots/panel-settings-language.png)

*设置页签只有语言一个选项，切换后立即生效并保存。*

## 日志

日志区按时间顺序显示最近的事件，主要包括：

- 状态变化和原因；
- 当前正在执行的操作，例如 `备份：请求中…`、`还原：完成`；
- 安全视图和回包隔离的切换；
- 还原 / 导入完成后的统计和 `警告：…`。

日志只保存在当前页面内存中，刷新页面后清空，不会上传到任何地方。写入完成后，
请至少检查一遍日志里有没有 `警告` 行。

## 写入保护机制

脚本对还原和 Wooting 导入使用同一套受保护的写入流程：

1. **安全视图**：把官方页切换到设置视图，避免官方页面在写入期间渲染过期数据；
   写入结束后再切回原视图。
2. **回包隔离**：写入期间官方页面收不到本次传输的回包，避免官方状态机被串台数据干扰。
3. **逐项校验**：写入后回读关键配置；丢写会自动重试一次，仍未生效的项记入 `警告`。
4. **单任务执行**：同一时间只允许一个写入任务，按钮在传输期间会禁用。
5. **布局确认**：备份布局与设备布局不一致时，必须手动确认；取消不会写入任何内容。

::: tip 只保留一个连接
同一时间只让一个页面或程序持有键盘的 HID 句柄和屏幕串口。第二个句柄可能让第一个
句柄的写入被固件忽略，也会让回读出现旧值。
:::
