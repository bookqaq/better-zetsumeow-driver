# 还原配置

还原会把一份备份 JSON 写回键盘。它与 Wooting 导入共用同一套受保护的写入流程；
区别是普通还原会**完整恢复备份中的设置**，包括清除备份里没有的高级键。

::: danger 先备份再还原
还原不会自动备份设备当前配置。请先按[备份配置](/backup)导出一份 JSON，
再执行还原。
:::

## 还原步骤

1. 按官方驱动页面的流程连接键盘（正常授权 HID 设备）。
2. 点击 **还原**，打开“还原设备配置”对话框。
3. 点击 **载入还原文件**，选择之前导出的 `zmeow-config-*.json`。
   - 文件会在对话框内立即解析并校验；
   - 校验通过后显示文件名和摘要，例如 `已载入 zmeow-config-20261117-223501.json — 3 个重映射层、61 个键色、12 个行程键、4 项特性 — 可以还原`；
   - 校验失败会显示原因，**确认还原** 按钮保持禁用。

![还原设备配置对话框：已载入合法备份并显示 ✓ 已载入摘要行，确认还原按钮变为可用](/screenshots/restore-dialog-loaded.png)

*校验通过后的对话框：摘要行给出解析结果与重映射层、键色、行程键、特性的数量，“确认还原”按钮同时变为可用。*

4. 点击 **确认还原** 开始写入。写入期间按钮禁用，请勿关闭页面或切换键盘。
5. 等待日志出现完成摘要，例如
   `还原完成：重映射 42、键色 61、行程 12、特性 4（已清除 2）`。
6. 检查紧随其后的 `警告：…` 行；如果没有警告，设备配置即已写入。
7. 写入成功后会弹出“刷新页面”对话框，按需选择 **立即刷新** 或 **取消**（见下文）。

::: info 取消的语义
在点击 **确认还原** 之前，选择 **取消**、关闭对话框或按 `Esc` 都不会写入任何内容。
点击确认之后传输已经开始，此时关闭对话框不会中止写入。
:::

## 布局不一致确认

当备份文件的布局与设备当前布局不同时，会先弹出 **布局不一致** 对话框：

- 对话框显示备份布局、设备布局，以及重叠按键数 `shared` 和被跳过的按键数 `skipped`；
- 点击 **同意还原** 才会继续，且只写入两种布局重叠的按键；
- 点击 **取消** 或按 `Esc` 会中止操作，不写入设备、不记错误。

备份中的按键如果在当前布局上不存在，会按硬编码跳过并记入 `警告`。例如把 79 键备份
还原到 65 键设备，F 区多出来的键不会被写入。

![布局不一致确认框：备份 extended79 还原到 compact65 设备，提示只写入重叠的 65 个按键、其余 14 个跳过](/screenshots/restore-mismatch-dialog.png)

*跨布局示例：备份使用 extended79 布局、设备是 compact65，点击“同意还原”后只写入两者重叠的 65 个按键，其余 14 个按键将被跳过。*

## 写入与校验

- **按差异写入**：只写入与设备当前值不同的项，相同值不会重复写。
- **回读重试**：重映射和行程写入后会回读；固件静默丢弃的写入会自动重试一次。
- **节奏控制**：写入之间保留与官方驱动相近的间隔，降低丢写概率。
- **高级键**：默认清除设备上存在、但备份里没有的高级键；如果备份时高级键列表读取失败
  （`featuresRead: false`），则保留设备现有高级键，不执行清除。
- **逐项跳过**：备份里当前布局不认识的键、颜色或行程会跳过并写入 `警告`。

## 完成后的刷新对话框

写入成功后，官方页面缓存的数据已经过期，脚本会弹出“刷新页面”对话框：

| 选择 | 结果 |
| --- | --- |
| **立即刷新** | 刷新驱动页，官方页面重新读取设备；刷新后通常需要重新选择 / 连接设备 |
| **取消** | 不刷新，保持当前页面；官方页面显示的数据可能不是最新 |
| 关闭（× / `Esc` / 点击遮罩） | 同“取消”，不会刷新 |

如果官方驱动应用未被识别，脚本会跳过这个对话框，并在日志中提示手动刷新页面。

## 还原与“恢复出厂”

还原恢复的是**备份拍摄时刻**的配置，不是出厂默认值。如果备份里包含已经改过的键位，
还原后依然是那些值。要恢复出厂设置，请使用官方驱动提供的重置功能。

## 常见警告

| 日志警告 | 含义 | 处理 |
| --- | --- | --- |
| `Retrying travel settings for …` | 部分行程写入未生效，正在自动重试 | 等待日志给出最终结果 |
| `Travel settings for … were not adopted after a rewrite` | 重试后仍有行程未写入 | 稍后重试该次还原；确认没有第二个 HID 句柄 |
| `Skipped … remap entries the active layout does not know` | 备份中有当前布局不存在的键 | 正常现象，跨布局时会出现 |
| `Skipped colour for unknown hardCode …` | 键色对应的键不存在 | 正常现象，跨布局时会出现 |
