# 数据与隐私

## 本地优先

脚本没有账号系统，也不包含遥测、统计或远程日志。配置读取、备份、转换和写入都在
当前浏览器页面内完成。

## 网络请求

运行时唯一的业务网络请求发生在你主动使用 **导入 Wooting 配置** 时：

| 项目 | 说明 |
| --- | --- |
| 请求目标 | `https://api.wooting.io`（Wooting 分享接口） |
| 触发条件 | 你输入分享码并点击 **导入** |
| 发送内容 | 分享码本身 |
| 返回内容 | 对应的 Wooting profile |
| 请求方式 | Tampermonkey 的 `GM_xmlhttpRequest`，固定带 `origin: https://wootility.io` |
| 失败回退 | 没有用户脚本管理器时回退页面 `fetch`；驱动页会被 CORS 拦截，此时导入会明确失败 |

除此之外，脚本不会向任何服务器上传配置、日志或设备信息。Tampermonkey 按脚本中的
`@updateURL` 检查更新属于脚本管理器行为，不经过本脚本代码。

## 本地保存的数据

| 数据 | 位置 | 生命周期 |
| --- | --- | --- |
| 界面语言 | 驱动页 `localStorage` 的 `zmeow-tap.locale` | 直到清除站点数据或卸载脚本 |
| 备份 JSON | 你选择的本地下载目录 | 由你管理 |
| 还原 / 导入的中间数据 | 当前页面内存 | 刷新页面即丢失 |
| 面板日志 | 当前页面内存 | 刷新页面即丢失 |

## 备份文件包含什么

备份包含键位、灯效、单键颜色、行程、高级键和杂项设置，以及产品信息和固件版本。
它**不包含**设备序列号（SN）或 `boardId`。

即便如此，备份仍能完整暴露你的键盘配置。请不要把备份文件上传到公开仓库、论坛或
在线剪贴板；分享配置时可先确认内容。

## 分享码与 Wootility

使用分享码导入时，分享码会发送到 Wootility 官方接口，并受其服务条款与隐私政策约束。
Wootility profile 本身可能包含你的键位和灯效配置，请按需分享，不要公开他人的分享码。

## 权限

| 权限 | 用途 | 是否必需 |
| --- | --- | --- |
| `GM_xmlhttpRequest` / `GM.xmlHttpRequest` | 获取 Wooting 分享配置 | Wooting 导入必需 |
| `unsafeWindow` | 页面 tap 注入 | 否，缺失时脚本无法观察官方页连接 |
| `@connect api.wooting.io` | 限定分享接口访问范围 | Wooting 导入必需 |
| 驱动页站点访问 | 在 `driver.zetsumeow.com` 注入 | 必需 |

脚本不申请其他网站的访问权限，也不在后台常驻运行。
