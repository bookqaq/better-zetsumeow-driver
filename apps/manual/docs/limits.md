# 已知限制

本页列出使用前值得了解的能力边界。多数限制来自浏览器、固件或官方驱动的既定行为，
不是脚本可以自行绕过的。

## 产品与布局

- 当前脚本只面向 Zetsu63 产品，支持 `compact65`（65 键）和 `extended79`（79 键）两种布局。
- 官方页面新增产品型号时，产品表校验会失败，状态变为 **已禁用**，需要脚本适配。
- 布局只在连接时读取一次。热插拔 F 区模块后，需要重新连接设备以刷新布局。

## 官方驱动页面版本

- 页面 tap 依赖官方驱动页面的资源指纹和协议解析。
- 官方页面更新后，指纹可能不再匹配，脚本会进入 **通过 tap 代理连接** 的只读状态，
  直到脚本发布适配版本。
- 页面更新后内部实现可能变化，但 tap 只依赖 Web API 与协议字节，不依赖官方内部实现。

## 设备连接

- 同一时间只应保留一个 HID 句柄。第二个页面 / 工具同时打开时，第一个句柄的写入可能被
  固件忽略，读回也可能返回旧值。
- HID 回包没有事务 id，无法完全避免并发请求之间的回包串台。
- 官方驱动每次连接都会重新申请设备并调用 `forget()`；脚本不阻止这一行为，也不应缓存旧句柄。
- 刷新页面后通常需要重新选择 / 连接设备。

## 浏览器

- 仅支持桌面版 Chrome / Edge。Firefox、Safari 和移动端浏览器不支持 WebHID / Web Serial。
- 页面必须通过 HTTPS 或 `localhost` 打开；`file://` 页面没有设备 API。

## Wooting 导入

- 只支持 60HE / 80HE 家族。Wooting One、Two 系列、UwU、Lekker 模块不支持，也不做部分迁移。
- profile schema 支持 9–15；低于 9 只做尽力导入并记录 legacy 警告；高于 15 直接拒绝。
- **DKS 不导入**：SDK 没有对应的写入命令，也不能等价转换成其他功能。
- **动态 RGB 效果不导入**：只导入静态逐键颜色（`rgb.kbdArray`）。
- **gamepad / lightbar / tachyon / digital mode / tick rate 不导入**：Zetsu 没有对应设置。
- **Fn2 及更多层忽略**：固定导入基础层 + 第一层 Fn（layer 0/1）。
- **导入是补丁**：没有静态键色就不改灯效，没有高级键就不清空设备现有高级键；
  也不会自动备份设备配置。
- 分享接口有限流（约 40 次 / 10 秒），且需要网络可达。

## 备份与还原

- 备份不包含设备 SN / `boardId`，但包含键位、灯效、行程等配置，仍需妥善保管。
- 备份是拍摄时刻的拷贝；“本次修改前”不等于“出厂默认”。
- 还原是差异写入，但无法绕过固件偶发丢写；脚本会回读并重试一次，仍失败的项记入警告。
- 跨布局还原只写入重叠按键；当前布局不存在的键、颜色和行程会被跳过。
- 正常还原会清除设备上存在、但备份里没有的高级键；执行前请确认备份包含需要保留的高级键。
  需要恢复出厂设置请使用官方驱动。
- 复杂配置（大量键色、行程、高级键）写入需要时间，期间应保持页面打开，不要同时操作设备。

## 屏幕

- 屏幕是独立串口设备，与键盘 HID 连接互不影响。
- 发布版不提供屏幕连接按钮；屏幕相关操作由官方驱动页负责。

## 语言与面板

- 语言设置只影响脚本面板，不改变官方驱动页面的语言。
- 面板日志只保存在当前页面内存中，刷新即清空。
- 面板显示的状态、指纹和帧数用于诊断；不构成对设备状态的持久记录。

## 真机验证范围

当前文档和脚本以固件 `1.1.1`、65 / 79 键布局为真机验证基线。其他固件和硬件组合通常可用，
但涉及写入行为的结论以实际设备和日志为准。反馈问题时请附上固件、布局和日志。
